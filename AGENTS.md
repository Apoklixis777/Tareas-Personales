## AGENTS

Crea una aplicación web para gestionar las tareas personales.


Prompt de requisitos y funcionalidades


Las funcionalidades que debe tener la App son estas:

1.- Crear tareas.

2.- Editar tareas

3.- Marcar tareas como completadas

4.- Eliminar tareas

5.- Filtrar tareas (todas/ completadas / pendientes)

6.- Persistencia en el LocalStorage (almacenamiento local en el navegador)

7.- Diseño Responsive

8.- Feedback visual ( hovers, focus, estados, etc.)



Preferencias de estilos y visuales que tengo para la app son estas:

1.- Colores rojos y cálidos

2.- Que la app este en idioma español.



Diseño:

Quiero que la aplicación esté en español y en el listado de tareas a la derecha del todo de cada tarjeta de tareas, que añadas la fecha de creación de la tarea.

Y hazme una pantalla de settings con un formulario donde yo pueda poner mi nombre, mis apellidos y un campo donde pueda poner una imagen url para que se vea como avatar en la web.


Stack: React, vite, tailwind css, typescript.
